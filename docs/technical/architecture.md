# 技术架构

1. **资源覆盖层**：卡图、头像和不改变结构的纹理优先使用同路径资源覆盖。
2. **视觉配置层**：`card_id -> visual_family -> action_profile`。
3. **视觉注册表**：启动时严格加载并验证 JSON；任何非法配置阻止自定义视觉启用。
4. **视觉分发器**：未来通过少量已核验的 Harmony Hook 选择动作 Profile，不修改原参数、不跳过原方法。
5. **Godot 动作与 VFX**：只播放本地视觉，伤害时序仍由原游戏控制。
